# Wine Guide — Support

Support page for **Wine Guide: Cellar & Pairings** (iOS).

- Something broken or a question? Open an [issue](https://github.com/waxeye7/wine-guide-support/issues)
- Privacy policy: [PRIVACY.md](PRIVACY.md)
- Manage or cancel a subscription: iPhone Settings → your name → Subscriptions
- Restore a purchase: Pro screen in the app → "Restore purchase"
